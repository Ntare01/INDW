# Indinzi Cultural Troupe — Website

A five-page, mobile-first site built in plain HTML/CSS/JS (no frameworks, no build step).

## Pages
- `index.html` — Home
- `about.html` — About Us
- `media.html` — Media (Instagram-Discover-style photo & video grid)
- `events.html` — Events
- `contact.html` — Contact

## How to preview it
Just open `index.html` in a browser — no server or install required.
(For the smoothest local testing, right-click the folder → "Open with Live Server" in VS Code, or run `python3 -m http.server` from this folder and visit `http://localhost:8000`.)

## Adding photos & videos to the Media page — the easy way
Everything on the Media page comes from **one file**: `js/media-data.js`.

1. Put your image or video file in the `assets/media/` folder.
2. Open `js/media-data.js` and copy one of the existing entries in the `MEDIA_ITEMS` array.
3. Update it:
   ```js
   {
     type: "image",                         // "image" or "video"
     src: "assets/media/my-photo.jpg",      // path to your file
     caption: "Short caption here",
     category: "performance",               // performance | workshop | behind-the-scenes | community
     big: false                             // true = larger featured tile (use sparingly)
   }
   ```
4. For videos, you can optionally add a `thumbnail` field (a still image shown before it's tapped).
5. Save the file and refresh the page. No other file needs to change.

New items you add to the **top** of the array show up first.

If you want a new filter category (e.g. "rehearsals"), add a button in `media.html` inside `.media-filters`:
```html
<button class="filter-chip" data-category="rehearsals">Rehearsals</button>
```
and use that same `category` value in your media items.

## Editing navigation, footer, or contact details
The header (top navbar + mobile bottom tab bar) and footer are shared across every page and
generated by `js/partials.js` — edit that file once and every page updates automatically.
Update the `NAV_LINKS` array to add/rename pages, and edit `buildFooter()` for contact details,
social links, address, etc.

## Editing colors and fonts
All colors and fonts are defined as variables at the top of `css/style.css` in the `:root` block —
change a value there and it updates across the whole site.

```css
--cream, --beige, --brown, --brown-deep, --gold ...
```

## The contact form
The form on `contact.html` currently just shows a confirmation message in the browser — it does not
send an email yet, since this is a static site with no backend. To make it functional, either:
- Connect it to a free form service like **Formspree** or **Netlify Forms** (just point the form's
  `action` at their endpoint), or
- Replace the handler in `js/main.js` (`initContactForm`) with a `fetch()` call to your own backend.

## Placeholder content
Photos, the sample videos, team names, and events in this build are placeholders so you can see the
full design in action. Replace:
- Hero and section images (currently `picsum.photos` placeholder URLs) with real photography.
- Media items in `js/media-data.js` with your real photos/videos.
- Team members in `about.html`, and events in `events.html`, with real names/dates.
- Email, phone, and social links in `js/partials.js` and `contact.html`.

## Notes on the mobile navigation
On screens narrower than 900px, the top navbar is replaced by a fixed **bottom tab bar** (Home /
About / Media / Events / Contact) for an easy, thumb-friendly, app-like navigation experience. On
wider screens, a standard horizontal navbar is shown instead. Both are generated from the same
`NAV_LINKS` list in `js/partials.js`.
